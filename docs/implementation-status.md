## 共同约束

- 保持 .NET Framework 4.8 / C# 5 原生实现，内嵌本地网页，无新增 Electron 运行依赖。
- 共享设置兼容缺失字段，保存后再发布；旧表单不能清空其他功能设置。
- 使用真实观测时间和稳定账号、窗口身份；保留旧值、重复本地快照不产生新观测，倒计时到期不证明额度恢复。
- 额度百分比历史与 Token 用量历史分别管理，不相互换算。
- 长期用量与排行必须共用可对账的会话/日期/模型事实；费率更新只改变费用，不改变 Token。
- 不修改源 Codex 日志或凭据；自动测试使用合成数据。实现阶段不安装或启动生产常驻程序。
